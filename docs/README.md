# 开发文档

本目录用于存放项目开发相关的文档和日志。

## 文件说明

- **DEVELOPMENT.md** - 开发日志，记录开发过程中遇到的问题、解决方案和技术细节
- **CHANGELOG.md** - 变更日志，记录项目的版本变更和重要更新
- **README.md** - 本文件，说明文档目录的结构和使用方法

## 使用指南

### 开发日志（DEVELOPMENT.md）
记录开发过程中遇到的问题、排查过程和解决方案。包括：
- 问题描述
- 排查步骤
- 可能原因
- 解决方案
- 相关文件

### 变更日志（CHANGELOG.md）
记录项目的版本变更，包括：
- 新增功能
- 功能修改
- 问题修复
- 安全更新

## 更新频率

- **开发日志**：遇到问题时及时记录
- **变更日志**：每次版本发布时更新
